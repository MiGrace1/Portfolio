## Context

AppTest is my final-year project, completed at KIAMA S.A.

## Problem

Verifying a web application requires several types of tests. AppTest aims to run them from a single platform.

## My contribution

- Design and development of the platform as my final-year project
- Business services and REST APIs with Java 21 and Spring Boot, using a hexagonal architecture
- Access security with Spring Security and JWT
- User interface with React, Next.js and TypeScript

## Technical challenges

The main challenge was bringing different types of tests into a single tool, with a consistent way to run them and read their results, whichever web application was under test.

## Outcome

AppTest aims to provide a modular, secure and scalable platform. Detailed results remain confidential.
