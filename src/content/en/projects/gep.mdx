## Context

A Cameroonian public administration needed to centralize the management of its assets: vehicles, land, buildings and IT equipment, along with its structures and locations. I worked on this project as a backend developer during my internship at KIAMA S.A.

## Problem

The data was scattered across a multi-sheet Excel file, with duplicates and outdated tables. There was no single reliable source for viewing or updating the assets.

## My contribution

- Data model design
- Data cleaning and migration
- Backend API development
- Administrator and user role management
- Acceptance testing and the V1.0 test report

## Technical challenges

The main challenge was moving from inconsistent Excel sheets to a single, coherent data model without losing useful information. This meant identifying duplicates, setting aside outdated tables, then migrating the remaining data to the new structure.

## Outcome

The platform is in production and replaces tracking by Excel file. Assets are now managed in a single application, with separate access levels for administrators and users.
