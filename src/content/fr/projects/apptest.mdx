## Contexte

AppTest est mon projet de fin d'études, réalisé chez KIAMA S.A.

## Problème

Vérifier une application web demande plusieurs types de tests. AppTest vise à les réaliser depuis une même plateforme.

## Ma contribution

- Conception et développement de la plateforme dans le cadre de mon projet de fin d'études
- Services métier et API REST avec Java 21 et Spring Boot, selon une architecture hexagonale
- Sécurisation des accès avec Spring Security et JWT
- Interface utilisateur avec React, Next.js et TypeScript

## Défis techniques

Le principal défi était de réunir différents types de tests dans un même outil, avec une façon cohérente de les lancer et d'en lire les résultats, quelle que soit l'application web testée.

## Résultat

AppTest vise à fournir une plateforme modulaire, sécurisée et évolutive. Les résultats détaillés restent confidentiels.
